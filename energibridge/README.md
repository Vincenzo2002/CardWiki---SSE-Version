# EnergiBridge

Conservare qui gli script e le istruzioni per eseguire le misurazioni
energetiche. Documentare versione dello strumento, sistema operativo, hardware,
comando applicativo o scenario di carico e durata della misura.

Usare condizioni equivalenti per baseline e versione migliorata. Salvare CSV,
grafici e note nella cartella `energibridge/` della relativa versione sotto
[sse-reports](../sse-reports/README.md).

La cartella è predisposta; non sono ancora presenti script o configurazioni.
