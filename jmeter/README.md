# JMeter

Conservare qui i piani di carico `.jmx`, gli eventuali piccoli dataset di test
e le istruzioni per ripetere gli scenari. Parametrizzare host e porta per usare
lo stesso piano con baseline e versione migliorata.

Documentare versione JMeter, preparazione dei dati, utenti, ramp-up, durata e
comando di esecuzione. Salvare output `.jtl`, report e screenshot nella cartella
`jmeter/` della relativa versione sotto [sse-reports](../sse-reports/README.md).

La cartella è predisposta; non sono ancora presenti piani o configurazioni.
